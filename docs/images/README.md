## 拍摄条件 / Capture conditions

- 插件包版本：**0.2.2** 候选（未发布；公开可下载版本仍为 0.2.1）。
- 宿主：**纯官方 npm runtime 0.2.1-alpha.5**（Cordis 4.0.5 / Schemastery 3.18.5）的真实 Web 设置页；Missher 配套 rc.2 与 alpha.2 本轮只做安装、Loader 与生命周期验收，未用于截图。
- 平台与视口：Linux x64，1280×720；窗口内小时活动区宽度与 `scrollWidth` 一致（桌面 559px，窄窗口 351px）。
- 数据：**完全合成**。152 条合成会话、累计 17 850 900 Token、今天（UTC）236 100 Token；24 个小时桶与合成种子逐一相等，例如 18 点为 92 400、19 点为 0。
- 方法：对真实页面取原始 JPEG 帧，仅做无损格式转换为 PNG，**像素未修改**，非生成式作图、非拼接。
- 覆盖内容：53 列 × 每列 7 格、每日/每周/累计各 371 格、零用量淡色与按用量加深的色阶、无边框小时区、青绿配色切换后 reload 保留、手动刷新。
- Tooltip：本次由点击与键盘焦点实际触发；鼠标移入显示的验证沿用此前未修改的 `local.9` 证据，不声称本轮做了自动鼠标移入测试。

## 隐私 / Privacy

图片不含个人会话内容、笔记、真实项目路径、主机名、端口、访问令牌或凭据；数据全部由合成种子生成，宿主运行在隔离 profile 中。

## 未覆盖 / Not covered

原生日常 Electron 界面、macOS、Windows 与 Apple Silicon 未在本轮用该版本验收；这些截图不能代表上述平台。
